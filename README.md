# 펫티켓 — 동네별 강아지 산책 지도

전국 시군구별로 **쓰레기통·급수대·동물병원·애견동반 장소**를 정리한 정적 페이지입니다.

- 사이트: https://seungsoos.github.io/petiquette-web/
- 앱(iOS): https://apps.apple.com/kr/app/id6794570453

데이터는 공공데이터와 이용자 제보를 바탕으로 하며 실제와 다를 수 있습니다.
페이지는 본 리포가 아니라 앱 저장소의 `scripts/build_web.py`로 생성됩니다.

> 🐾 반려동물 배설물은 지자체·시설마다 배출 방법이 달라요.
> 공용 쓰레기통에 버릴 수 없는 곳도 있으니 현장 표지를 확인해 주세요.
